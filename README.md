# Prueba técnica full stack

Repositorio de la evaluación técnica para desarrollador full stack

## Dónde está cada cosa

- `docs/`: respuestas de la prueba por punto
- `backend/src/orders/`: ejemplo del endpoint `POST /api/v1/orders`
- `sql/`: esquema e índices usados en la solución
- `diagramas/`: fuentes y renders de diagramas
- `frontend/`: estructura base del frontend

## Comandos útiles

- `npm run typecheck`: revisa TypeScript
- `npm run build`: compila el backend
- `npm run dev`: levanta la API en desarrollo
